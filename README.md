# 照片轉影片工具 (photo2video)

用 Rust + egui 寫的桌面小工具，把一連串照片合成一支影片。

## 下載

不想自己建置的話：

- **最新版直接下載**：<https://github.com/Yellow5363/photo2video/releases/latest/download/photo2video-windows-x64.zip>（永遠指向最新版）
- [Releases 頁面](https://github.com/Yellow5363/photo2video/releases/latest) 可看歷史版本與更新紀錄

zip 內含 `photo2video.exe`、`ffmpeg.exe` 與使用說明，解壓即可使用。程式啟動時會自動檢查更新並在視窗底部提示。

## 主畫面

版面比照 Lightroom：最上面是功能表列（`檔案` / `編輯` / `模組` / `輔助說明`），下面一條模組列，**左邊可切換功能模組**——目前有「🎬 照片轉影片」、「💨 去煙霧」、「🎆 煙火疊圖」、「🎥 煙火影片去煙霧」、「✨ 優化影像」與「📂 檔案管理」，再下面才是該模組的工作區。各模組的狀態各自保留，切走再切回來就是離開時的樣子。

## 優化影像

整批照片一次調好，不必一張一張進 Lightroom 拉滑桿。選一批照片或整個資料夾，程式會**每張各自分析**，把十二條調色滑桿放到那張該有的位置，再自動找出主體另外加強：

1. **選類型**：「鳥類」「一般風景」「風景人像」。三種用的是同一套量測，差別在目標值——鳥類偏通透與對比、風景偏層次與去朦朧、人像則刻意把對比與清晰度收斂。
2. **自動調色**：量白平衡的色偏、中間調亮度、反差寬度、暗部有多擠、霧有多厚、彩度與局部反差，逐項回推成滑桿的值。刻意的低調（夜景、逆光剪影）與高調（雪景、白底）照片不會被硬拉回「正常亮度」。整批覺得太重或太淡就拉「強度」（0～200%），比十二條各拉一次快。
3. **主體強化**：自動找出「哪一塊是重點」——靠細節密度（對到焦的那一塊）、與周圍的亮度／顏色反差，以及膚色範圍。主體提亮、加局部對比與銳利，背景不動。
4. **人像柔膚**：膚色範圍內的細紋與色斑抹勻，眼睛、嘴唇、髮際線這些高反差的邊緣留著；人像模式下主體強化會**自動避開皮膚**，銳利只加在頭髮、眼睛與衣服上。
5. **看得到才算數**：按「顯示主體範圍」，預覽會變成「主體維持原樣、膚色染粉紅、其餘壓暗染藍」，圈到哪裡一眼就看得出來。判偏了把對應的滑桿調小或歸零即可。

每張都可以再手動微調（動任一條調色滑桿就變成那張的個別設定），右側面板還有跟其他模組一樣的裁切。按「💾 全部存檔」整批存回各自的原始資料夾（檔名加上 `_優化`），或「📁 另存新檔」自己挑資料夾。**原始照片一律不會被更動。**

判斷主體用的是統計特徵，不是神經網路（程式裡沒有模型檔）：判得出「哪一塊是重點」，判不出「那是什麼東西」。膚色尤其如此——被燈光打亮的煙與雲，顏色和皮膚幾乎一樣。所以強化一律是依權重漸進套上去的，不是二值開關，判偏了也只是輕重之差。

## 檔案管理

和影像處理無關的雜事收在這裡，模組畫面最上面是一條功能列，目前只有「**1. 資料備份**」一項。

指定來源與目的兩個資料夾（可拖曳；重開程式兩格是空的，但選資料夾的對話框會各自記得上次挑到哪裡；按「＋ 加入一組」可以一次排好幾組來源 → 目的，照順序全部做完，有問題的那組只跳過它、原因寫在底下），按「▶ 開始備份」即可——**按下去一定會先重新比對一次**（兩邊的檔案隨時在變），再把要做的事列成確認框讓你過目；想先看清單就按「🔍 比對」（這一步不動任何檔案）。規則就三條：**同名的檔案，來源比較新就覆蓋掉目的那一份**、**目的沒有的直接拷過去**、**目的地多餘的檔案**勾了「保留」就不動、沒勾就刪掉（預設勾著；刪的是丟資源回收筒，做完會多一顆「↩ 還原剛才刪除的 N 個檔案」可以一鍵放回）。可選「含子資料夾」整棵一起備份。Mac 留下的附屬檔（`._*`、`.DS_Store` 那一票）、`Thumbs.db` 與 `$RECYCLE.BIN` 等系統資料夾一律當作不存在，其餘**隱藏檔照樣備份**——隱藏不等於不重要（Lightroom 的 `xxx.lrcat-data` 資料夾與裡面的 `desktop.ini`、`PackageIcon.ico` 都在內；資料夾的隱藏／系統屬性也會一起帶過去，自訂圖示才會跟著對）。

目的挑到上一層時，底下會**自動套一層與來源同名的資料夾**：來源 `F:\2025_鳥_精選`、目的 `O:\` → 實際寫入 `O:\2025_鳥_精選`（不存在就自動建立），畫面上會把這個位置寫出來。直接挑到 `O:\2025_鳥_精選` 就用它，不會再多一層。

**只會寫到目的資料夾**——來源全程唯讀；目的那份比較新時原封不動留著，統計列顯示「目的較新 N（不動）」。修改時間會跟著拷過去，所以同一組資料夾再備份一次是「一件都不用做」；時間差 2 秒以內當成同一份（FAT32／exFAT 的時間戳只有 2 秒解析度）。來源與目的是同一個、或一個在另一個裡面會直接擋掉。動手前的確認框會把這次要做的每一類事各寫一行。

## 使用方式（照片轉影片）

執行 `target\release\photo2video.exe`，操作步驟：

1. **加入照片**：點「選擇資料夾」或「選擇照片（可多選）」，也可以直接把照片或資料夾拖曳進視窗，或在啟動時把照片／資料夾當參數帶入（支援「開啟方式」）。照片會依檔名自然排序（img2 會排在 img10 前面），在下方縮圖上按右鍵可移除單張或清空全部，← → 方向鍵可切換預覽。
2. **設定每秒張數 (fps)**：1～60，預設 10，例如 2 代表每秒播 2 張照片；修改後會自動記住，下次開啟直接套用。
3. **調色（套用至整部影片）**：右側面板可調整色溫、色調、曝光度、對比、亮度、陰影、白色、黑色、清晰度、鮮豔度、飽和度（各 -100～+100）。點選下方任一張縮圖即可在中央大預覽區即時檢視調色效果；預覽與輸出使用同一套 FFmpeg 濾鏡，所見即所得。轉換時參數會套用到影片中的**每一張照片**。
4. **主體追蹤（連拍飛鳥、跑動的人）**：右側「主體追蹤」區按「⚡ 自動框選全部」，程式比對每張與前後兩張的差異、逐張找出「自己在動」的那一團並框起來；你再逐一檢查（縮圖會標「⚠ 沒框到／要檢查」），不對的直接在預覽上重畫一個框，不要的照片可整批移除（Delete 鍵或「移除沒框到的 N 張」）。輸出時每張各裁下一塊以主體為中心的畫面，**主體一直待在畫面正中央**；「鏡頭範圍」決定切多大一塊、「平滑度」決定鏡頭跟得多穩，兩條都是即時重算。自動找不到時可自己框幾張，再用「▶ 從手動框追蹤」把其餘的補齊。
5. **字幕（依段落設定）**：按字幕區右上的「＋ 新增段落」，設定「從第 X 張到第 Y 張」與要顯示的文字（可多行），這段照片就會共用同一句字幕；可新增多個段落，適合上百張照片的場合。字型（微軟正黑體、標楷體、Arial 等系統字型）、大小、文字顏色、外框粗細/顏色、位置（上/中/下）、半透明底框皆可調整，樣式全域共用；有字幕的照片縮圖右上角會標示 💬，點選縮圖可預覽該張的實際效果。
6. **轉場、動態縮放與背景音樂**：「轉場與音樂」區塊可選「淡入淡出」轉場、勾選 Ken Burns 動態縮放（照片緩慢推近/拉遠，啟用任一者輸出會提升為 30fps）、勾選「結尾淡出」讓影片最後畫面漸漸變黑（預設開啟）；背景音樂支援 MP3 / WAV / M4A / FLAC / OGG（也可直接拖進視窗），可調音量與結尾淡出，音樂比影片短會自動循環、比影片長會自動裁切。
7. **選擇輸出格式**：MP4 / MKV / MOV / AVI（H.264）或 WebM（VP9），並可選解析度（720p～4K）。照片會等比例縮放置中，不足處補黑邊（調色在補黑邊之前套用，黑邊不會被調亮）。轉換會自動偵測並使用硬體編碼（NVENC / QSV / AMF），沒有可用 GPU 時退回 libx264。
8. 按「**開始轉換**」，選擇儲存位置後開始轉換，會顯示進度條。右側各設定區塊的標題可點擊收合。

> 第一次轉換時會自動下載 FFmpeg（約 80MB），之後不需再下載。

## 命令列模式

也可以不開視窗直接轉換：

```
photo2video.exe --cli <照片資料夾> <fps> <輸出檔>
```

例如：`photo2video.exe --cli D:\photos 2 D:\out.mp4`
（輸出格式由副檔名決定：mp4 / mkv / mov / avi / webm）

## 建置

```
cargo build --release
```

## 技術說明

- GUI：eframe / egui（深色剪輯風格介面，自動載入微軟正黑體顯示繁體中文）
- 轉檔：ffmpeg-sidecar（自動下載並呼叫 FFmpeg，用 concat demuxer 串接照片）
- 支援的照片格式：jpg / jpeg / png / bmp / webp / tif / tiff
